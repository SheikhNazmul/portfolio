# Sheikh Nazmul — dark portfolio

Two-page responsive portfolio built with HTML, CSS, and JavaScript. Open index.html locally or publish this directory as a static site.

## Pages
- index.html: hero, featured work, about teaser, contact form
- about.html: biography, portrait, capabilities, education and experience
- assets/sheikh-nazmul-cv.pdf: downloadable CV

The contact form validates required fields and opens the visitor's default email application via mailto. It does not transmit messages to a backend.

The site uses the public GitHub avatar for the photo panels. Replace it with a preferred portrait when available.

Project years follow the latest public GitHub activity reviewed on 19 October 2026. The Expense Tracker repository describes a full-stack personal finance product; no AI capability is claimed. The plant classifier's README does not report accuracy metrics.

Contact email was taken from the supplied CV. For publication, verify that you want the address and downloadable CV public.
